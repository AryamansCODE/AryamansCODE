# 🕷 Spider-Man: Beyond the Web — Cinematic Movie Website

A small, cinematic single-page fan website for a Spider-Man movie, built with plain HTML, CSS, and JavaScript — no build step required.

## Features

- **Full-screen cinematic hero** with an AI-generated 2K (16:9) Spider-Man key-art image, slow Ken Burns drift, mouse parallax, and a dark vignette film grade
- **Story section** with animated stat counters (critics score, runtime, legacy year)
- **Character cards** for the heroes and shadows of the film, with glowing emblems and hover lift
- **Cinematic moments gallery** mixing the key art with quote panels
- **Ticket call-to-action** with a fixed parallax background
- Scroll-reveal animations, sticky blur navigation, spider-web corner decorations, and full mobile responsiveness (with `prefers-reduced-motion` support)

## Hero image

The hero artwork was generated with **Higgsfield — Nano Banana Pro** at **2K resolution, 16:9** aspect ratio, and is served from Cloudinary's CDN with automatic format/quality optimization.

## Run it

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
